# web-based-tic-tac-toe-40808-40922

A simple web-based two-player Tic Tac Toe game built with React.

## How to Run

1. From this folder, install dependencies:

   ```
   npm install
   ```

2. Start the application for local development:

   ```
   npx serve -s web-based-tic-tac-toe-40808-40922/public
   ```

   Alternatively, use your preferred React dev server and ensure the `src` and `public` directories are included appropriately.

3. Open your browser and navigate to `http://localhost:3000` (or the port printed by your dev server).

## Features

- Two player turn-based grid
- Win and draw detection with restart button
- Clean and responsive UI
